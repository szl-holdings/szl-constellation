# SZL Estate Graph (v1)

The SZL Holdings estate as a computable graph, exported from the constellation's
trust-path engine (HF Space SZLHOLDINGS/szl-constellation).

- 67 nodes: 49 estates (tier-attributed), 8 verticals, 3 trinity hubs (second_brain / anatomy / ouroboros), 7 shared-substrate anchors
- 126 edges: synapse (49), wired-into (10), governed-by (8), runs-on (56), trinity (3)
- Files: graph.json (canonical), nodes.csv, edges.csv, RECEIPT.txt (recomputable sha256, UNSIGNED_HONEST)

Purpose: the bench fleet learns the graph of a healthy estate. Drift = the live
graph diverging from the receipted graph. Post-2026-09-04 owner directive: sentra
is the sole Assurance Command (absorbed aegis); killinchu holds resilience.
